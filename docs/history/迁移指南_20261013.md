> 生成时间：2026-10-13；源机器项目路径 `D:\Download\Agent\MedEvidence`。

## 一、需要带走的文件

两种方式任选：

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| A. 整个文件夹 | 把 `D:\Download\Agent\MedEvidence` 拷到新电脑任意目录 | U 盘 / 局域网 / 网盘 |
| B. 单文件包 | 拷贝 `D:\Download\Agent\MedEvidence_20261013.zip`（同目录的 `.sha256.txt` 是校验值） | 网盘 / 怕丢文件 |

- 文件夹约 **567 MB**；zip 包大小见文件属性。
- **不需要**带走：Python 环境、C 盘任何内容。
- 所有脚本无绝对路径依赖（全部相对项目根目录），换盘符 / 换用户名 / 换目录都能直接跑。

## 二、新电脑准备（约 10 分钟）

1. 安装 **Python 3.10+**：https://www.python.org/downloads/ （安装时勾选 "Add python.exe to PATH"）。
2. （可选，仅在遇到证书报错时需要）：
   ```powershell
   py -m pip install certifi truststore
   ```
3. 把项目放到合适位置即可（含中文的路径也能正常工作）。

## 三、校验迁移完整性

```powershell
cd <项目路径>
py -X utf8 scripts\verify_data.py
```

期望输出全部 ✅（PMC 936 / WHO 16 / CDC 61 / MeSH 2 / DO 2 / PubMed 931+10）。
出现 ❌ 说明拷贝不完整，重拷对应目录即可。

## 四、继续工作

常用命令（在项目根目录执行）：

```powershell
py -X utf8 scripts\verify_data.py                                  # 数据校验
py -X utf8 scripts\extract_pmc_text.py                             # 重建提取文本（可重复跑）
py -X utf8 scripts\download_pmc_oa.py --email 你的邮箱 --per-disease 3   # PMC 增量下载（自动跳过已有）
py -X utf8 scripts\who_iris.py --query "handle:10665/344424" --links    # WHO 条目/直链解析
py -X utf8 scripts\fetch_pubmed_meta.py                            # 刷新 PubMed 元数据
```

网络注意：

- 若新电脑访问 GitHub raw / jsDelivr 不通（只有 Disease Ontology 下载需要），先设置代理：
  ```powershell
  $env:HTTPS_PROXY="http://127.0.0.1:端口"; $env:HTTP_PROXY="http://127.0.0.1:端口"
  ```
- 证书问题脚本会自动处理（truststore → certifi → 系统默认）；都不可用时安装 `certifi`。
- `cdc.gov` 对纯脚本请求返回 403，`download_cdc_pages.py` 已内置 curl 回退，无需处理。

## 六、备选：只带代码、在新电脑重下数据

