# 跨机器迁移说明（把项目复制到另一台电脑继续）

## 一、复制什么

**整个 `MedEvidence` 文件夹**（约 570 MB）。里面已经包含全部内容：
数据（PMC/WHO/CDC/MeSH/DO/PubMed 元数据）、脚本、配置、许可登记、文档。
没有任何内容绑定当前机器，也没有需要重新下载的东西。

## 二、怎么复制

1. 确认没有正在运行的下载脚本（当前所有下载任务均已完成）。
2. 推荐用 robocopy（保留时间戳、稳定）：

   ```powershell
   robocopy "D:\Download\Agent\MedEvidence" "X:\你想要的路径\MedEvidence" /E /R:1 /W:1
   ```

   或直接用资源管理器拖拽 / 压缩包（用支持 Unicode 的压缩工具）。
3. **路径可以不同**：脚本全部使用相对路径（以脚本自身位置推算项目根目录），换盘符、换目录都不影响。
   移动后对原机器没有依赖；原目录可从旧机器删除。

## 三、新电脑准备

1. 安装 **Python 3.10+**（python.org 官方安装包，勾选 py launcher 和 Add to PATH）。
2. （可选）只有在 HTTPS 报证书错误时才需要：`py -m pip install certifi`
   （脚本会自动依次尝试 truststore → certifi → 系统默认，装任何一个即可）。
3. 校验复制完整性（在 MedEvidence 目录下）：

   ```powershell
   py -X utf8 scripts\verify_corpus.py
   ```

   **预期输出**：
   - PMC 文章目录 936 篇；抽查 15 篇通过
   - 许可登记约 21 个文件全部通过（MeSH / DO / WHO / PubMed）
   - CDC 61 条、PubMed 931 条
   - 结论：全部通过 ✅

   如果输出 ❌，按提示补复制对应文件即可（不整也可以重跑 `verify_corpus.py` 复查）。

## 四、继续进度

- **已完成的下载不会重来**：PMC/WHO/CDC/MeSH/DO/PubMed 元数据均已落盘；
  各下载脚本带断点续传逻辑（读 manifest 跳过已下载），以后增量下载在任何机器上都接着走。
- **下一步工序与机器无关**（按 `docs/数据下载清单_v1.md` 继续即可）：
  1. 精筛（用 PubMed 元数据的文献类型 + MeSH 词）
  2. WHO PDF / 全库统一文本化
  3. 建检索索引（BGE-M3 + BM25 + Qdrant）
- 若新电脑需要**补下新数据**（一般不用）：
  - 下载脚本会自动使用 Windows 系统代理；若某些域名（GitHub raw 等）直连不通，
    设置环境变量后重跑：`$env:HTTPS_PROXY="http://127.0.0.1:7897"; $env:HTTP_PROXY="http://127.0.0.1:7897"`（端口换成实际值）。
  - cdc.gov 对脚本 UA 返回 403 的问题脚本内已自动回退 curl.exe，无需处理。

## 五、环境备忘（新机器常见坑）

| 现象 | 处理 |
| --- | --- |
| 输入 `python` 没反应/静默失败 | 用 `py -X utf8` 代替（`python` 可能是 Windows 商店占位程序） |
| HTTPS 证书错误 | `py -m pip install certifi` 后重跑 |
| 中文输出乱码 | 脚本已统一 UTF-8 输出；终端切 UTF-8 或忽略（不影响文件内容） |
| 磁盘位置 | 数据总计约 570 MB；后续模型与索引预计再占 15–25 GB |
